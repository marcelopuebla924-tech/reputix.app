## Constraint definitions extracted
Exact definitions were captured for `businesses`, `reviews`, `business_owner_claims`, `business_photos`, and `complaints`.

Notable integrity rules:
- Reviews: each score, when supplied, must be 1–5; status is pending/published/rejected; business FK cascades on delete; user FK sets null.
- Owner claims: relationship types owner/partner/manager/independent_worker/new_entrepreneur; verification levels activity/business_responsible/owner; evidence types enumerated; status pending/activity_verified/responsible_verified/verified/rejected; unique business+user; business/user FKs cascade.
- Photos: status pending/approved/rejected; unique storage_path. No FK was found for `business_photos.business_id` in this table's constraint result; column is text. Keep this as a known schema inconsistency to verify against application behavior rather than changing it silently.
- Complaints: complaint text length 10–5000; status pending/published/rejected/resolved; business FK restricts delete; user FK sets null.
- Businesses: primary key on id; active-proposal uniqueness is implemented as a partial unique index, not a table constraint.

## Indexes captured
- Business proposals: unique normalized name/category/city/address for pending or approved records.
- Owner claims: unique business+user and one verified owner per business.
- Business photos: unique storage path.
- Reviews: indexes support business/date, published business/time, published visit date, status/date, and user/date access.
- Complaints: indexes support business/date and user/date.
All extracted definitions are saved in this checkpoint for staging reconstruction.

## View access verification
Five public views checked:
- `business_hourly_patterns`, `recent_review_highlights`, `weekly_business_rankings`: security_invoker=true; SELECT granted to anon/authenticated/service_role.
- `owner_business_dashboard`, `owner_business_hourly_patterns`: no security_invoker reloption; SELECT denied to anon, granted to authenticated/service_role.
This reinforces that owner views need a dedicated security review and staging tests for cross-tenant isolation before any release.
